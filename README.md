# herning_machine_learning

## Setup

```bash
# 1. Install uv (once per machine)
curl -LsSf https://astral.sh/uv/install.sh | sh          # Linux / macOS / WSL
# Windows PowerShell instead: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# 2. Clone and build the environment
git clone https://github.com/Frode-Henrol/herning_machine_learning.git
cd herning_machine_learning
uv sync
```
